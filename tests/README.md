# 시험 (오프라인)

실리태번도, AI 호출도 없이 미트볼을 시험합니다. 돈이 들지 않습니다.

```
npm install     # 처음 한 번 (jsdom: 앱 화면을 그려 보는 가짜 페이지)
npm test
```

- `harness.mjs` — 가짜 실리태번(채팅 · 저장 · 설정)과 엔진. 「답을 읽는 AI」의 대답은 시험 안에 글로 적어 둔 것을 씁니다.
- `*.test.mjs` — 날짜 · 답 읽기 · 다시 뽑기 · 돈 · 옛 기록 가져오기 · 모든 앱 화면 그리기.
- 시험에 나오는 이름과 대사는 전부 지어낸 것입니다. 실제 채팅 내용은 넣지 않습니다.

실리태번과 주고받는 부분(답 도착 순서, 스와이프, 실제 모델의 대답)은 여기서 볼 수 없습니다. 그럴 때만 실리태번에서 직접 확인합니다.
